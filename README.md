# AE2 Crafting Tree Legacy Unofficial


本项目是 Kasumi_Nova 的 **[AE2CTL (AE2 Crafting Tree Legacy)](https://github.com/NovaEngineering-Source/AE2CT-Legacy)** 的**非官方分支**。
- **本分支新增改动**：
  1. **配方树截图**：补全了原mod未完成的合成树截图功能；
  2. **流程图导出**：新增一键导出配方树的流程图功能，支持 **SVG（矢量图）** 与 **PNG（高清位图）** 两种格式（左键导出，右键切换格式）。
---

## 💡 功能与操作

在 AE2 终端的**合成确认界面**右上角点击按钮即可进入「合成树」界面：

| 操作 / 快捷键 | 功能说明 |
| :--- | :--- |
| **鼠标左键拖拽** | 移动 / 平移合成树画布 |
| **鼠标滚轮** | 缩放画布（0.25x ~ 1.0x） |
| **鼠标左键单击** | 选中节点 / 单击空白取消选中 |
| **↑ / ↓ / ← / →** | 在选中节点的父级、子级与兄弟节点间平滑切换，视口自动跟随居中 |
| **Ctrl + ← / →** | 仅在**原料缺失**的节点间快速跳转 |
| **仅缺失按钮** | 切换完整合成树 / 仅显示缺料的子树分支 |
| **流程图按钮** | **左键**导出流程图（保存在 `.minecraft/screenshots/`），**右键**切换 SVG / PNG 格式 |
| **截图按钮** | 生成合成树的完整截图（支持普通与仅缺失视图） |

# AE2 Crafting Tree Legacy Unofficial (English)

This project is an **unofficial fork** of Kasumi_Nova's **[AE2CTL (AE2 Crafting Tree Legacy)](https://github.com/NovaEngineering-Source/AE2CT-Legacy)**.
- **Changes in this fork**:
  1. **Crafting Tree Screenshot**: Implemented and completed the unfinished crafting tree screenshot feature from the original mod;
  2. **Flowchart Export**: Added a one-click recipe tree flowchart export feature, supporting both **SVG (vector)** and **PNG (high-res raster)** formats (left-click to export, right-click to toggle format).

---

## 💡 Features & Controls

Click the button in the top-right corner of the **Crafting Confirmation screen** in the AE2 terminal to enter the Crafting Tree view:

| Action / Shortcut | Description |
| :--- | :--- |
| **Left-click Drag** | Pan / move the crafting tree canvas |
| **Mouse Wheel** | Zoom in / out (0.25x ~ 1.0x) |
| **Left-click** | Select a node / Click empty space to deselect |
| **↑ / ↓ / ← / →** | Navigate smoothly between parent, child, and sibling nodes (viewport auto-centers) |
| **Ctrl + ← / →** | Quick-jump only between nodes with **missing ingredients** |
| **Missing Only Button** | Toggle full crafting tree / show only branches with missing ingredients |
| **Flowchart Button** | **Left-click** to export flowchart (saved in `.minecraft/screenshots/`), **Right-click** to toggle SVG / PNG format |
| **Screenshot Button** | Capture a full screenshot of the crafting tree (supports both normal and missing-only views) |
