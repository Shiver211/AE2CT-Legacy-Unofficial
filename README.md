# AE2 Crafting Tree Legacy Unofficial


本项目是 Kasumi_Nova 的 **[AE2CTL (AE2 Crafting Tree Legacy)](https://github.com/NovaEngineering-Source/AE2CTL)** 的**非官方分支**。
- **本分支新增改动**：
  1. **配方树截图**：补全了原mod未完成的合成树截图功能；
  2. **流程图导出**：新增一键导出配方树的流程图功能，支持 **SVG（矢量图）** 与 **PNG（高清位图）** 两种格式（左键导出，右键切换格式）。
---

## 💡 功能与操作

在 AE2 终端的**合成确认界面**右上角点击按钮即可进入「合成树」界面：

| 操作 / 快捷键 | 功能说明 |
| :--- | :--- |
| **鼠标左键拖拽** | 移动 / 平移合成树画布 |
| **鼠标滚轮** | 缩放画布（0.25x ~ 1.0x） |
| **鼠标左键单击** | 选中节点 / 单击空白取消选中 |
| **↑ / ↓ / ← / →** | 在选中节点的父级、子级与兄弟节点间平滑切换，视口自动跟随居中 |
| **Ctrl + ← / →** | 仅在**原料缺失**的节点间快速跳转 |
| **仅缺失按钮** | 切换完整合成树 / 仅显示缺料的子树分支 |
| **流程图按钮** | **左键**导出流程图（保存在 `.minecraft/screenshots/`），**右键**切换 SVG / PNG 格式 |
| **截图按钮** | 生成合成树的完整截图（支持普通与仅缺失视图） |
